# Аудит v2.1 — 8 сентября 2026

## Что поставлено

Опциональный context-tools v0.1: предчтение по байтам запрошенного диапазона, UI warn/enforce, одноразовый полный read, tool-less bulk-reader через Pi model registry, явное сессионное согласие на модель/папки, bounded input/output, quote/line/hash validation, отмена/таймаут и worker receipts. Добавлен валидатор сравнительного учёта full-read / targeted-read / delegated без двойного сложения стоимости.

Установка: `node scripts/kit.mjs context-tools --target PROJECT`. По умолчанию warn; отправка модели выключена до интерактивного подтверждения. Core не зависит от модуля. Code-writer/Portal/AiKA не включены.

## Что реально проверено

- **85/85 тестов**, failures 0, skips 0, cancellations 0; из них 40 прежних core-регрессий и 45 новых проверок.
- Linux, Node v24.14.1, git version 2.49.0. Выполнен именно `node --test --test-reporter=tap`.
- 27 файлов global/project-template/profiles побайтно совпадают с v2. Постоянный AGENTS-бюджет: 2407 UTF-8 байт; каталог опционального инструмента добавляет собственный overhead.
- MJS/TS syntax, JSON, skill/prompt metadata и opt-in defaults — `verification/static-checks.json`.
- Проверены согласие/отзыв, смена сессии во время подтверждения, freeze бюджета, повторная проверка модели перед отправкой, исключения путей, binary/UTF-8, ограниченные диапазоны и giant single line, неверные ссылки/цитаты, stale source, отсутствие tools/истории, один worker, timeout/abort, сохранение usage при отказе, неизвестная стоимость, артефактные ошибки, установка/сохранение config/откат.
- Валидатор сравнения проверен на синтетических числах. Шаблон с неизвестной стоимостью сохраняет `null` и отсутствие verdict; это не benchmark.
- Bash-обёртки проверены на синтаксис. Матрица GitHub CI не запускалась здесь.

Полный TAP и машиночитаемые результаты находятся в `verification/`. История v2 сохранена **отдельно** в `AUDIT-V2-RU.md` и `verification/v2-baseline/`; это не новые результаты.

## Граница достоверности

Pi CLI и TypeBox не установлены в среде аудита. Адаптер проверен через mock контекста/реестра, TypeScript — на синтаксис, не полную типизацию зависимостей. **Не было реальной загрузки расширения в Pi, native Windows/macOS, Node 22 или платных model calls.** Для первого применения нужен smoke-тест из `CONTEXT-TOOLS-RU.md`; при недостающей возможности Pi включение worker блокируется.

Соответствие цитаты исходнику не доказывает правильность вывода. Guard охватывает локальный read, а не все shell/custom tools, и не является security sandbox. Известные credential paths блокируются, встроенные секреты надёжно не распознаются. Проверяйте доверие к проекту/расширениям и папки до отправки. Отмена не гарантирует отсутствие уже начисленной оплаты.

Cost — оценка Pi по каталогу, не инвойс. Usage включён в tool result, когда он получен; неизвестные расходы нельзя заменить нулями. Не прибавляйте worker второй раз к Pi session totals. Полная экономия реальных задач ещё **не измерена**, процент не заявляется.

Spotify: доступные README использованы как архитектурное вдохновение. Код hooks/scripts/evals получить не удалось, он не аудирован и не заимствован. README-проценты Spotify не воспроизводились.

## Состав доказательств

- `CHANGES.patch` — различия с поставленным v2, кроме самого patch и FILE-HASHES.
- `FILE-HASHES.json` — SHA-256 всех остальных файлов; это контроль целостности, не цифровая подпись.
- `verification/CHANGED-FILES.json` — список отличий; generated hash/patch и сам список исключены.
- `verification/RESULTS.json` и `test-output.tap` — фактический офлайн-прогон.

Для обычного обновления используйте архив и opt-in установщик, не применяйте patch вслепую поверх персональных AGENTS. Миграция с v2 не требует `init --force` или повторного глобального install.
