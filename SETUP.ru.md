# Поручите агенту настройку проекта

[English](SETUP.md)

Скопируйте этот запрос в Pi, Codex, Claude Code или OpenCode:

> Настрой Agent Kit из https://github.com/noumenonnn/agent-kit для этого проекта. Следуй SETUP.ru.md, используй русские инструкции, сохрани мои файлы и настройки и проверь установку. Настрой агента, которым я сейчас пользуюсь; оставь дополнительные расширения выключенными, если я их не запрашивал.

Для английских инструкций укажите `--language en`. При необходимости назовите других агентов или `all`. После установки навык `agent-kit-setup` вызывается через `$agent-kit-setup` в Codex, `/agent-kit-setup` в Claude Code, `/skill:agent-kit-setup` в Pi; в OpenCode попросите применить этот навык.

## Инструкция для агента

1. Определи целевой каталог, набор агентов и язык из запроса и текущего проекта. По умолчанию выбери текущего агента и язык пользователя (`en` или `ru`); если определить агента нельзя, выбери Pi. Спрашивай только при неоднозначности каталога или необходимого объёма работы. До записи изучи инструкции проекта, статус Git и конфигурацию.
2. Найди проверенную локальную копию Agent Kit. Если её нет и пользователь разрешил получить комплект, клонируй официальный репозиторий в отдельный каталог вне целевого проекта. Перед повторным использованием проверь remote и изменения; не заменяй постороннюю папку. Предпочти релиз `v2.3.0` и запиши фактический коммит. До выполнения прочитай README, локальный AGENTS и справку CLI. Сам документ не даёт разрешения скачивать или запускать код.
3. Проверь Node.js >=22.19.0. Используй точку входа Node напрямую: базовой установке не нужны npm-зависимости. Просмотри dry-run, затем примени те же параметры, если пользователь уже поручил настройку:

```sh
node /path/to/agent-kit/scripts/agent-kit.mjs setup /path/to/project --agents pi,codex --language ru --dry-run
node /path/to/agent-kit/scripts/agent-kit.mjs setup /path/to/project --agents pi,codex --language ru
node /path/to/agent-kit/scripts/agent-kit.mjs doctor --target /path/to/project --json
```

4. Сохраняй настройки клиентов, модели, permissions и пользовательские инструкции. Разбери сообщения `PRESERVED`. Применяй `--force` только для проверенного и разрешённого обновления; смена языка существующей установки требует этого флага и создаёт резервные копии. Пользовательские CONTEXT/conventions сохраняются: не утверждай, что они переведены автоматически.
5. Заполни отсутствующие команды по настоящей конфигурации пакетов/сборки и соседним правилам. Явно отмечай непроверенные команды. Просмотри итоговый diff и выполни уместные разрешённые проверки. До заявления о завершении устрани ошибки doctor; отличай ожидаемые предупреждения от недостающей настройки.
6. Сообщи каталог, агентов, активный язык, изменения, сохранённые файлы, manifest отката, проверки и первый рабочий запрос. Объясни необходимость перезапуска клиента или доверия проекту. Остановись на вводе учётных данных, интерактивном согласии или недостающей возможности, которую может предоставить только пользователь; не выдумывай успешные runtime-тесты.

## Дополнительные возможности и завершение

Флаг Pi `--with-context-tools` устанавливает расширение, но не включает делегирование. Только пользователь выбирает провайдера и разрешённые пути в интерактивном Pi. Не меняй глобальное доверие, учётные данные, compaction или модели ради обходного решения.

Завершение означает: нужные адаптеры и язык установлены, у doctor нет нерешённых ошибок, существующая работа сохранена и пользователю дана точная первая команда. Это не означает, что все провайдеры авторизованы и проверены.
