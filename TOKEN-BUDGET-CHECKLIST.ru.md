# Контрольный список контекста и стоимости

[English](TOKEN-BUDGET-CHECKLIST.md)

## Стабильный постоянный контекст

- [ ] AGENTS — короткий указатель со значимыми ограничениями безопасности, а не справочник.
- [ ] Команды и предметная область проекта читаются по необходимости.
- [ ] В системном префиксе нет меняющихся дат и истории задач.
- [ ] Нет дублирующих описаний навыков и широких каталогов расширений.
- [ ] Метаданные сторонних навыков «только по запросу пользователя» сохранены; Pi использует `/skill:name`.

## Качество свидетельств

- [ ] Поиск предшествует широкому чтению, но контекста достаточно, чтобы избежать локально правдоподобной ошибки.
- [ ] Учтены staged/unstaged/untracked файлы и правильная база ревью.
- [ ] Вывод ограничен байтами И длиной строк; журналы потоковые, контекст ошибок сохранён.
- [ ] Обрезанный журнал отмечен как неполный.
- [ ] Проверены обнаружение и число тестов, критерии приёмки; одного кода 0 недостаточно.

## Накладные расходы процесса

- [ ] Для небольшой задачи по умолчанию один исполнитель.
- [ ] У каждого делегирования есть польза, область и владение файлами, контракт результата и условие остановки.
- [ ] В общей папке один пишущий исполнитель; изоляция worktree явная.
- [ ] Глубокое и лёгкое ревью не дублируются без причины.
- [ ] Смена этапа или handoff оправдывает новый префикс кэша, а не автоматически отбрасывает полезный контекст.
- [ ] Core сохраняет auto-compaction; альтернатива подключается только после smoke-проверок.

## Измерение вместо обещаний экономии

- [ ] Сравниваются равноценные задачи, критерии приёмки и фактический учёт провайдера.
- [ ] Учтены родитель, дети, повторы, ревью и влияние кэша.
- [ ] Основной показатель — полная стоимость и время на принятую задачу при достаточной успешности и уровне регрессий.
- [ ] Дополнительные показатели — некэшированный ввод, вывод, чтение/запись кэша, инструменты, ходы и размер контекста.
- [ ] Ошибки и блокировки записаны; их исключение не создаёт видимость дешевизны.
- [ ] Нет неподтверждённых процентов улучшения или универсального «оптимального контекста».
