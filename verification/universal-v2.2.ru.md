# Agent Kit v2.2: проверка

[English](universal-v2.2.md)

Дата: 2026-09-08. Хост: Windows. Это локальные результаты, а не заявление о CI на каждой платформе.

## Автоматические проверки

- `node --test`: 102 теста, 99 успешных, 0 ошибок, 3 пропуска.
- Пропуски: два POSIX-теста сигналов/групп процессов в Windows и прежняя PowerShell-обёртка, заблокированная политикой хоста. Прямые Node-тесты CLI/установщика прошли. Политика выполнения не менялась.
- `node scripts/check-kit.mjs`: успех. Pi policy — 2407 байт, portable policy — 599 байт, метаданные lean — 569 байт.
- Добавлено покрытие четырёх адаптеров, аддитивной настройки, preview без записи, сохранения настроек/инструкций, override, повторяемости, отката Pi addon одной транзакцией, отсутствующих/изменённых файлов в doctor, точных UTF-8-выдержек, JSON-бюджетов, устаревания, неверных путей, binary, hardlinks и конфликтов вывода.

Первоначальный прогон имел одну ошибку политики PowerShell. Тест теперь отмечает именно это ограничение хоста как пропуск и сохраняет отказ при других ошибках запуска.

## Нативный Pi 0.85.1

Официальный SDK с фиксированной версией установлен во временную папку разработки через --ignore-scripts; он не является runtime-зависимостью Agent Kit. Выполнено:

```sh
node scripts/smoke-pi.mjs --sdk /temporary/path/to/@earendil-works/pi-coding-agent
```

| Универсальный проект | 3 | 7 | 0 |
| Проект с context-tools | 3 | 7 | 1 |

Зарегистрированный handler context-tools status сообщил `Guard: warn; bulk-reader: OFF` через перехваченный UI callback. Сессия агента и запросы провайдера не создавались. Диагностика ресурсов комплекта пуста. Машиночитаемый результат: [pi-v2.2-smoke.json](pi-v2.2-smoke.json).

## Дистрибутив

`npm pack --ignore-scripts` создал локальный архив с необходимыми скрытыми папками шаблонов. Архив распакован; его CLI установил все четыре адаптера и Pi context-tools в отдельную фикстуру. Установка и JSON doctor прошли; пустой проект ожидаемо предупредил об отсутствующих командах проекта. Пакет не публиковался.

## Ограничения

Полная работа TUI Pi и реальные запросы провайдера не проверялись. Клиенты Claude Code/OpenCode отсутствовали; контракты ресурсов сверены с первичной документацией и тестами. Установленный Codex CLI сообщил 0.153.4, но аутентифицированная сессия не выполнялась. Интерактивный успешный путь мастера не прогонялся в настоящем TTY; проверены отказ без терминала и общий путь setup. Межплатформенный CI настроен, а не локально выполнен здесь.

Байты контекста и целостность измерены; улучшение стоимости, задержки или качества принятой задачи не подтверждено контролируемой оценкой моделей. См. [EVALUATION.ru.md](../EVALUATION.ru.md).
