# Рабочий процесс Agent Kit

Выберите `efficient-task` для выполнения задачи, `efficient-context` для чтения и диагностики, `efficient-handoff` для передачи работы, `agent-kit-setup` для настройки или обновления комплекта. Для обычного вопроса дополнительные этапы не нужны. Навыки направляют работу; разрешения определяет среда выполнения.

## Сбор контекста

Начинайте с путей и символов: `rg --files`, затем ограниченный `rg -n`. Исключайте генерируемые файлы. Останавливайтесь, когда известны поведение и точка изменения; расширяйте чтение по зависимостям. Лимит контекста не оправдывает сокрытие нерешённого вопроса.

```sh
node .agent/scripts/context-pack.mjs --file src/example.ts --range 10:80 --max-bytes 16384 --out .agent/tmp/context.json
node .agent/scripts/context-pack.mjs --verify .agent/tmp/context.json
```

Повторяйте `--file`; следующий `--range start:end` относится к этому файлу. Без диапазона берётся весь файл. Превышение лимита приводит к ошибке до записи результата. SHA-256 относится ко всему исходному файлу; проверка выявляет устаревший источник и изменение выдержки. Это проверка происхождения, а не смысла. Перед передачей проверьте содержимое на секреты.

## Команды и проверка

Запускайте конечные команды через `compact-run.mjs`, указывая фактический исполняемый файл. Изучайте журнал и `diff-summary.mjs --no-log`. Код 0 не доказывает обнаружение тестов или нужные утверждения. В Windows для shell-команд явно вызывайте shell.

## Состояние и передача работы

Отделяйте стабильные инструкции от статуса задачи. Сохраняйте цель, ограничения, решения, источники, изменённые пути, точные проверки и следующий шаг. После сжатия или сброса перепроверьте изменчивые факты. Оставляйте автоматическое сжатие включённым, если не выбрана и не проверена его замена.

## Делегирование

Передавайте узкую независимую задачу, выбранные источники и контракт результата вместо всей родительской переписки. Согласуйте владение файлами в общей папке. Опциональному Pi-расширению нужно согласие через интерактивный интерфейс; другие клиенты не получают от комплекта дополнительных прав.

## Измерение

Сравнивайте одинаковые принятые задачи: качество, общее время, все токены и стоимость, повторы, исполнителей и ревью. Неизвестные величины оставляйте неизвестными. Байты не равны токенам токенизатора. Комплект не управляет кэшем провайдера и не обещает экономию.
