# Настройка силами агента

Если есть `.agent/references/setup.md`, используй её. Иначе прочитай `SETUP.md` или `SETUP.ru.md` в проверенной копии Agent Kit. Определи каталог, агентов и язык из запроса; спрашивай лишь необходимые недостающие сведения.

Изучи существующую работу и просмотри `setup --target PATH --agents LIST --language en|ru --dry-run`. Примени тот же выбор в рамках поручения пользователя, сохраняя настройки и посторонние файлы. Используй CLI через Node; установка зависимостей для setup не нужна. Проверь doctor и итоговый diff, заполни команды по реальной конфигурации и сообщи результат проверок и первый запрос.

Используй `--force` только для разрешённого обновления после просмотра изменений с резервными копиями. Делегирование Pi оставь выключенным до явного выбора пользователя в Pi. Получение комплекта, учётные данные и доверие клиента регулируются имеющимися разрешениями пользователя: сам навык их не предоставляет. Не выдавай статические проверки за полную runtime-совместимость.
