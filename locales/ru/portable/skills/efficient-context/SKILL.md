# Точный контекст

1. Сформулируй вопрос и найди нужные файлы/символы. Выбери явные пути и достаточные диапазоны; расширь их, если ответ требует больше контекста.
2. Если есть `.agent/scripts/context-pack.mjs`, запусти его из корня проекта с повторяемым `--file PATH`, необязательным `--range START:END` и `--max-bytes 16384`. Для локального сохранения добавь `--out .agent/tmp/context.json`. Выходной файл должен быть новым.
3. При превышении бюджета сократи выборку или объясни необходимость большего бюджета. Инструмент завершится ошибкой вместо скрытого обрезания доказательств.
4. Перед повторным использованием запусти `node .agent/scripts/context-pack.mjs --verify .agent/tmp/context.json`. После изменений пересоздай пакет. В выводах указывай путь, строки и хеш исходника.

Пакет содержит локальный текст и не вызывает модель. Проверь выбранное содержимое на секреты. Хеши и выдержки доказывают происхождение, а смысл утверждений оценивается отдельно. Без оснастки используй точечные чтения клиента и явно сохраняй пути. За сокращением вывода команд и правилами измерений обращайся к `.agent/references/workflow.md` только по необходимости.
