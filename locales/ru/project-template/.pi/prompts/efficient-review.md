Проверь изменения относительно намерения:
${@:-уточни намерение, если его нельзя установить из задачи}

Определи базу сравнения; учти релевантные staged, unstaged и untracked файлы, а не только git diff. Для работы в ветке установи merge base. Читай окружающий код для проверки конкретного опасения. Проверь корректность, контракты, границы безопасности, регрессионное покрытие и область задачи.
Верни применимые замечания: серьёзность, файл и строку, свидетельство, последствие, минимальное исправление. Отдели подтверждённые ошибки от непроверенных рисков; укажи пробелы покрытия даже при отсутствии замечаний. Отсутствие найденного дефекта само по себе не означает готовность к выпуску.
Не редактируй исходники и не запускай изменяющие их проверки. Тесты с записью относятся к отдельному этапу проверки. По умолчанию не добавляй ещё одно ревью. Переключение модели в той же сессии не создаёт независимые свидетельства; если требуется независимое ревью, используй отдельный контекст с той же задачей, diff и свидетельствами, без предыдущего вердикта.
