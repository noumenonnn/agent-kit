Выполни задачу:
$@

Изучи релевантный существующий код и текущие изменения пользователя. Установи критерии приёмки; уточняй только неоднозначности, меняющие реализацию. Внеси минимальную согласованную правку, выполни подходящие проверки и сообщи свидетельства.
Не запускай автоматически подагентов, переключение моделей, handoff, запись плана или несколько процессов ревью. Сообщи о препятствии, если задача неясна, рискованна или повторные попытки не дают новых свидетельств. Остановись вместо зацикливания.
Используй установленные навыки, только когда их подход существенно применим. Не затирай постороннюю работу, не устанавливай зависимости и не публикуй изменения без разрешения в задаче.
Верни изменения, проверенное поведение с точными командами, ошибки, заблокированные проверки и оставшийся риск. Нулевой код процесса сам по себе не доказывает, что тесты выполнялись.
