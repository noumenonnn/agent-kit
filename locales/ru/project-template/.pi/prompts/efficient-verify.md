Проверь текущие изменения. Область:
${@:-изменённое поведение и его интеграционные границы}

Изучи staged, unstaged и untracked пути. Выбери команды из фактической конфигурации репозитория. Перед запуском прочитай незнакомые скрипты. Сначала выполни конечные целевые проверки, затем более широкие соразмерно риску. Сборки и тесты могут записывать кэши и артефакты: это не shell-процесс только на чтение. Не включай автоисправления, не обновляй снимки, не устанавливай зависимости и не меняй код лишь ради зелёного результата.
При наличии используй compact-run; изучи контекст ошибок и итоговое число тестов. Подтверди обнаружение ожидаемых тестов. Отфильтрованная сводка или код 0 не являются вердиктом тестирования. Не проверяй одновременно с записью в ту же рабочую папку.
Сообщай PASS только при успехе релевантных приёмочных проверок; FAIL — для наблюдаемых ошибок; BLOCKED/NOT RUN — для отсутствующей возможности или недоступной проверки. Укажи команды, пути к свидетельствам, пропуски и остаточный риск. Невозможность выполнения никогда не превращай в PASS.
