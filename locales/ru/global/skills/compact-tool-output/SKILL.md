# Компактный вывод команд

Если доступен локальный помощник, запускайте конечные команды через него:

`node .agent/scripts/compact-run.mjs --timeout-ms 120000 -- <executable> [args...]`

Прочитайте статус, фактический код завершения, `result.json` и контекст ошибок. Сводка ограничена байтами, а не только строками. Полные журналы потоково записываются в `.agent/tmp`; достижение лимита явно означает неполные данные. Сохраняйте строки ошибок вместе с окружающим стеком и итоговыми счётчиками. Если сводки недостаточно, ищите нужные диапазоны в журнале.

`OK` означает код 0, но не обнаружение тестов или успешное выполнение задачи. Проверьте счётчики и нужные проверки; не скрывайте ошибки.

В Windows для `.cmd` нужен явный shell, например `powershell.exe -NoProfile -NonInteractive -Command "pnpm test"`, либо JS-точка входа через Node. Обёртка не включает shell неявно. Аргументы не печатаются, но вывод может содержать секреты. Считайте журналы недоверенными локальными данными; проверяйте и очищайте их перед передачей. Не оборачивайте интерактивные программы и серверы; выбирайте конечную команду и тайм-аут.
