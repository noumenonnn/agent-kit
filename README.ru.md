# Agent Kit

**Достаточный контекст. Предсказуемая настройка. Pi, Codex, Claude Code и OpenCode.**

[English](README.md) · [Полное руководство](UNIVERSAL-RU.md) · [Участие](CONTRIBUTING.ru.md) · [Изменения](CHANGELOG.ru.md)

[![Проверки](https://github.com/noumenonnn/agent-kit/actions/workflows/ci.yml/badge.svg)](https://github.com/noumenonnn/agent-kit/actions/workflows/ci.yml) [![MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Agent Kit готовит новый или существующий репозиторий к разработке с ИИ. Он устанавливает специализированные навыки, инструкции проекта и Node.js-инструменты без зависимостей. Существующие инструкции, настройки и выбор моделей остаются под вашим контролем.

Pi поддерживается как полноценная интеграция: шаблоны запросов, опциональный guard чтения, ограниченный модельный worker и нативный формат пакета.

## Быстрый старт

Нужны **Node.js 22.19+** и отдельно установленный агент разработки:

```sh
git clone https://github.com/noumenonnn/agent-kit.git
cd agent-kit
npm run wizard -- --language ru
```

Повторяемая настройка без интерактивных вопросов:

```sh
npm run setup -- --target ../my-project --agents all --language ru --dry-run
npm run setup -- --target ../my-project --agents all --language ru
npm run doctor -- --target ../my-project
```

Целевая папка может быть новой или существующей и должна находиться вне комплекта. Выберите агента через `--agents pi`, `codex`, `claude` или `opencode`; допустим список через запятую. По умолчанию используется Pi. Устанавливать зависимости комплекта не требуется.

В Windows используйте `npm.cmd`, если PowerShell блокирует `npm.ps1`, либо напрямую `node scripts/agent-kit.mjs wizard --language ru`.

Откройте проект в выбранном агенте:

| Агент | Первый запрос | Интеграция |
| --- | --- | --- |
| Pi | `/efficient-task Добавь X и проверь Y` | Общие навыки и 7 нативных шаблонов |
| Codex | `$efficient-task Добавь X и проверь Y` | Общие навыки и AGENTS.md |
| Claude Code | `/efficient-task Добавь X и проверь Y` | Нативные навыки проекта и CLAUDE.md |
| OpenCode | `/efficient-task Добавь X и проверь Y` | Общие навыки и 7 нативных команд |

Установщик создаёт проектную памятку `.agent/GETTING-STARTED.md`. Выберите `--language en` или `--language ru`; обновления сохраняют язык. Обе версии хранятся в `.agent/translations/` вне автоматического поиска ресурсов. Для смены языка нужен `--force`; сначала просмотрите `--force --dry-run`. Пользовательские документы проекта сохраняются.

## Поручите настройку агенту

Скопируйте запрос в своего агента разработки:

> Настрой Agent Kit из https://github.com/noumenonnn/agent-kit для этого проекта. Следуй SETUP.ru.md, используй русские инструкции, сохрани существующие настройки и изменения, подключи агента, в котором я сейчас работаю. Покажи план изменений, примени настройку, выполни doctor и нужные проверки, объясни, как начать работу.

[Процедура настройки агентом](SETUP.ru.md) охватывает новые и существующие проекты, обновление, проверку и критерии завершения. После установки навык `agent-kit-setup` служит той же точкой входа для следующих изменений.

## Что входит

- **Четыре навыка:** настройка комплекта, выполнение задачи, сбор точного контекста и передача работы. `--preset deep` добавляет шесть специальных навыков.
- **Контекст по необходимости:** небольшой стабильный блок инструкций, тематические справки и явный выбор файлов и строк.
- **Проверяемые выдержки:** UTF-8-бюджеты, SHA-256 полных источников и проверка свежести. Превышение лимита вызывает отказ, а не скрытое обрезание.
- **Компактный вывод проверок:** ограниченные выдержки в терминале, локальные журналы и реальные коды завершения.
- **Безопасная настройка:** просмотр без записи, сохранение настроек, управляемые блоки инструкций, учёт установки и откат с проверкой конфликтов.
- **Офлайн-работа:** setup не обращается к сети или моделям и не устанавливает сторонний код.

## Точный контекст без запроса к модели

Из подготовленного проекта:

```sh
node .agent/scripts/context-pack.mjs --file src/main.ts --range 20:90 --max-bytes 16384 --out .agent/tmp/context.json
node .agent/scripts/context-pack.mjs --verify .agent/tmp/context.json
```

Повторяйте `--file` для дополнительных источников. Без `--range` берётся весь файл. Бюджет включает сериализованный JSON; выходной путь должен быть новым. Проверка подтверждает целостность источника и выдержки, а не смысловую корректность ответа. Байты не равны токенам.

## Опциональные Pi context-tools

```sh
npm run setup -- --target ../my-project --agents pi --with-context-tools --language ru
```

В доверенной интерактивной сессии Pi выполните `/reload`, затем `/context-tools status`. Guard начинает с предупреждений, worker выключен. Для делегирования пользователь интерактивно выбирает модель и пути. [Настройка и поведение](CONTEXT-TOOLS-RU.md).

Нативные hooks guard/worker реализованы **только для Pi**. Другие адаптеры предоставляют навыки, инструкции и переносимые инструменты; они не перехватывают вызовы инструментов.

Репозиторий также является локальным Pi-пакетом: `pi install /absolute/path/to/kit -l`. Это альтернативная загрузка навыков/шаблонов, а не дополнительный шаг после настройки проекта. Для полной оснастки используйте `setup`.

## Обновления и откат

Повторная настройка добавляет адаптеры и идемпотентна. Просмотрите обновления с `--force --dry-run`, затем примените `--force`. Настройки клиентов и пользовательские контекст и правила сохраняются. Обновление управляемых инструкций сохраняет окружающий текст.

Каждая операция выводит путь manifest резервной копии. Для отмены:

```sh
node scripts/agent-kit.mjs restore --target ../my-project --manifest ../my-project/.pi-starter-backups/RUN/manifest.json --dry-run
```

Уберите `--dry-run` для отката. Отменяйте операции в обратном порядке; поздние пользовательские правки блокируют конфликтующий откат. [Полный жизненный цикл](UNIVERSAL-RU.md).
